# 🩺 Diabetes Dashboard – Power BI

An interactive **Power BI dashboard** designed to analyze diabetes-related data and transform raw data into clear, meaningful visual insights.

The dashboard provides an interactive way to explore patient-related metrics, identify patterns, and support data-driven understanding through dynamic visualizations.

---

## 📊 Project Overview

The **Diabetes Dashboard** is a Business Intelligence project developed using **Microsoft Power BI**.

The project focuses on:

* Exploring diabetes-related data
* Analyzing important health and demographic indicators
* Identifying patterns and relationships within the dataset
* Creating interactive visualizations
* Presenting key metrics through an easy-to-understand dashboard

---

## 🎯 Objectives

* Transform raw diabetes data into meaningful information.
* Build an interactive and user-friendly dashboard.
* Analyze important factors related to diabetes.
* Provide clear visual summaries of the dataset.
* Practice data cleaning, transformation, visualization, and dashboard design using Power BI.

---

## 🛠️ Tools & Technologies
